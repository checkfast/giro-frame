# Configurazione Checkfast

Il file `docs/config.js` contiene già il deployment Apps Script fornito.

In Apps Script → Impostazioni progetto → Proprietà script, verificare:

- `APP_ORIGIN`: `https://checkfast.github.io`

Repository previsto: `giro-frame`.
Pubblicare GitHub Pages dal branch `main`, cartella `/docs`.
Link previsto dopo la pubblicazione: https://checkfast.github.io/giro-frame/

Il link previsto non è una conferma che il sito sia già pubblicato. Il deployment Google e il collegamento completo devono essere provati dopo la pubblicazione.
